The Design Thinking Process

How I engineered this digital portfolio

1. Empathize

Before writing a single line of code, I stepped into the shoes of my potential users. I realized that people view websites in vastly different lighting conditions. More importantly, I considered users with visual impairments, such as color blindness, who often struggle with traditional web designs. Empathy taught me that aesthetics must never compromise usability.

2. Define

Based on my user research, I defined my core problem: "How can I build a personal portfolio that showcases my passions (like Ice Hockey and Web Development) while providing a universally readable, strain-free user experience for everyone?"

3. Ideate

I brainstormed various interactive solutions. I decided that a standard static page wasn't enough. I sketched out a multi-theme concept (Light, Dark, and Colorblind) and planned an interactive Lightbox gallery. This approach would make exploring my hobbies engaging without cluttering the main layout.

4. Prototype

I built the structural prototype using Semantic HTML5 and styled it with CSS Flexbox and CSS Grid. The biggest breakthrough was setting up CSS Variables (`:root`) to handle the color schemes dynamically, laying the foundation for a flawless theme-switching mechanism.

5. Test & Refine

Testing was rigorous. Using integrated browser Tools, I simulated different mobile screen sizes to ensure responsive design. I discovered a critical bug where navigating between pages reset the user's theme. Through iterative testing, I successfully patched this by engineering a JavaScript `URLSearchParams` routing solution.
