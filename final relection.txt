Building this portfolio was honestly a huge eye-opener for me. Instead of just doing the bare minimum for an assignment, I wanted to build something I could actually be proud of—a site that genuinely feels like "me," combining my coding journey with my love for ice hockey and speedcubing. I started from the ground up, using proper semantic HTML so screen readers could actually understand the page structure, and then used CSS Flexbox and Grid to make sure everything looked good on any screen size.

The design thinking process completely changed how I looked at this project. I used to just focus on making things look cool, but the "Empathize" stage made me realize that people experience the web differently. That's why I didn't just stop at a basic Dark Mode. I built a custom 3-way theme toggle that includes a high-contrast colorblind mode. It took a lot of tweaking with CSS variables and JavaScript, but making the site visually accessible to everyone felt incredibly rewarding. This inclusive approach also ties perfectly into my support for UN Global Goal 3 (Good Health and Well-being) by promoting a more accessible digital space.

The absolute biggest headache of this project, though, was getting the JavaScript to work smoothly across different pages. Originally, I tried using localStorage so the website would remember if you picked Dark Mode when you clicked over to the "Behind the Curtain" page. But since I was opening the files locally on my computer, the browser's strict security rules completely blocked it and crashed all my interactive scripts. It was super frustrating. After researching, I found that I accidentally added a launch that blocked Chrome from running my code locally.

Looking back, the coolest part of this project wasn't just writing the code but learning how to fix it when it broke. Spending hours in debugging my own errors made me feel less like a student just typing tags and more like an actual web developer. I am really proud of the advanced features I managed to pull off in this portfolio.
