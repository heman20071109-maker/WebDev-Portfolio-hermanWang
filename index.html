Design Thinking Process

In building this portfolio, I applied the design thinking process. I empathized with users by understanding they might prefer a dark background for better reading. I ideated by sketching the layout, and prototyped this final version using HTML, CSS, and JS to ensure a clean and modern user experience.

Accessibility Statement

This website is designed with accessibility in mind. I used semantic HTML5 tags (like header, main, footer) for better screen reader navigation. All images include descriptive alt text, and my toggleable Dark Mode provides a high-contrast color scheme to reduce eye strain for visually sensitive users.
