Design Thinking Process

To build this portfolio, I strictly followed the Design Thinking framework. Empathize: I realized users view sites in different lighting conditions and some have visual impairments. Define: The problem was creating a universally readable UI. Ideate: I brainstormed a multi-theme concept. Prototype & Test: I built and refined a 3-way toggle (Light, Dark, and Colorblind mode) using CSS variables and JavaScript to ensure maximum readability for everyone.

Accessibility Statement

This website prioritizes web accessibility (a11y). I implemented full semantic HTML5 tags (nav, main, section) to assist screen readers. All media elements have descriptive alt text. Most importantly, I engineered a three-color-scheme system featuring a high-contrast Colorblind Mode (yellow/cyan on black) to assist visually impaired users, alongside a Dark Mode to reduce eye strain.
