Behind the Curtain

My Web Development Journey & Reflection

1. Developer Tools & Code Screenshots

Throughout the creation of this portfolio, VS Code and Chrome Developer Tools were my most essential companions. I heavily utilized the DevTools "Elements" panel to visually adjust the cubic-bezier animations and the Grid layout gaps in real time. The "Console" tab was also crucial for debugging my JavaScript, specifically when writing the array logic for the 3-way theme toggle and diagnosing missing source maps from third-party extensions.

2. Final Reflection (Development Process)

Building this personal portfolio has been a highly rewarding experience that allowed me to synthesize everything from the "Intro to Web Development" course. My primary goal was to transcend basic requirements and reach the "Extending" level by anticipating user needs and developing innovative solutions to complex coding challenges.

Applying Design Thinking & Challenges: To ensure exceptional user experience, I applied the Design Thinking process. During the Empathize and Define stages, I recognized that users have varying visual preferences and accessibility needs. This led me to the Ideate and Prototype phase, where I engineered a complex 3-color scheme system. The most significant challenge was implementing the Colorblind Mode. I had to write complex JavaScript array logic to cycle the button through three states (Light -> Dark -> Colorblind). In CSS, I utilized custom properties (:root variables) to seamlessly override colors and add a high-contrast dark overlay to the background image without breaking the layout.

Advanced Interactivity: Beyond the themes, I further challenged myself by writing advanced JavaScript for an interactive Lightbox image gallery and an integrated background music (BGM) toggle. I learned how to precisely manipulate the Document Object Model (DOM) and manage multiple event listeners simultaneously, ensuring smooth transitions without crashing the browser.

Conclusion: This journey deeply enhanced my understanding of how HTML semantics, CSS Flexbox/Grid, and complex JavaScript integrate. I successfully shifted my mindset from merely writing code to thinking like a true developer who prioritizes accessibility and user empathy. I am incredibly proud of the professional-grade functionalities in this portfolio.
