Behind the Curtain

My Web Development Journey & Reflection

1. Developer Tools & Code Screenshots

Throughout the creation of this portfolio, VS Code and Chrome Developer Tools were my most essential companions. I heavily utilized the DevTools "Elements" panel to visually adjust the cubic-bezier animations and the Grid layout gaps in real time. The "Console" tab was also crucial for debugging my JavaScript, specifically when writing the array logic for the 3-way theme toggle, integrating the video into the Lightbox, and fixing Intersection Observer logic.

2. Final Reflection (Development Process)

Building this personal portfolio has been a highly rewarding experience that allowed me to synthesize everything from the "Intro to Web Development" course. My primary goal was to transcend basic requirements and reach the "Extending" level by anticipating user needs and developing innovative solutions to complex coding challenges.

Applying Design Thinking & Accessibility: During the Empathize and Define stages, I recognized that users have varying visual preferences and accessibility needs. I engineered a complex 3-color scheme system featuring a high-contrast Colorblind Mode. I also prioritized A11y by ensuring all media tags, including the HTML5 video, have descriptive aria-label and alt tags for screen readers.

Advanced Interactivity & Challenges: To achieve "Extending" level functionality, I implemented two major complex JavaScript features:

1. Enhanced Media Lightbox: I wrote conditional DOM logic (tagName.toLowerCase() === 'video') to allow my modal window to seamlessly support and auto-play both images and HTML5 videos, resolving a bug where videos previously broke the image-only modal.
2. Intersection Observer API: I researched and applied this advanced API to trigger smooth scroll animations as elements enter the viewport. The main challenge was ensuring the animation only fired once per element to optimize browser performance, which I solved using the observer.unobserve() method.

Conclusion: This journey deeply enhanced my understanding of how HTML semantics, CSS Flexbox/Grid, and complex JavaScript integrate. I successfully shifted my mindset from merely writing code to thinking like a true developer who prioritizes accessibility, performance, and user empathy.
